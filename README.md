# GuitarPico
A Guitar Hero (hard)mod to make a wireless PC/Bluetooth enabled controller

## What does it do? 

essentially what I just said... except for some key features I plan to add

- working onboard leds (already inside the controller)
- some form of a pairing button
- power switch
- settings config

## Hardware

I plan to use a Raspberry Pi Pico 2W that has Bluetooth capabilities to connect the controller to a device, it will have all inputs rewired directly into the Pico and the original main board is getting completely removed
The actual controller I will be using is a GH Live controller for the Xbox One which I have even more reason to mod this one since it needs a quite pricey dongle to connect but I do plan to add a list of supported controllers that use the same connections for the buttons
The controls on the controller all run on one of the following
- A generic potentiometer
- Keyboard switches
- Membrane buttons
